# 01-GLM-5.3-Flash vLLM 部署调用

## vLLM 简介

`vLLM` 是一个高性能的大语言模型推理与服务框架，具备以下特点：

- 高效的 KV 缓存与内存管理：基于 `PagedAttention` 显著降低显存浪费，提升长文本与高并发场景下的吞吐。
- 兼容 OpenAI 接口：可直接以 `OpenAI API` 形式对外提供 `completions` 与 `chat completions` 能力，便于与现有生态集成。
- 多 GPU 并行与易扩展：支持 Tensor Parallel 等策略，参数简单、易于横向扩展吞吐与上下文长度上限。
- 生态良好：与 `HuggingFace`/`ModelScope` 模型仓库无缝衔接，支持思考内容解析、工具调用等多种推理特性。

## 关于 GLM-5.3-Flash

`GLM-5.3-Flash` 是智谱（Z.ai）开源的 GLM 系列新一代轻量级模型，采用 MoE（Mixture of Experts）架构，主打低成本、高效率的推理体验。

主要特性：

- **混合思考模式**：支持思考/非思考双模式，可通过聊天模板中的 `enable_thinking` 参数自由切换，兼顾推理深度与响应速度；
- **轻量高效**：Flash 系列主打免费与低门槛部署，单卡与多卡环境均可轻松运行；
- **更强的 Agent 能力**：原生支持函数调用（Function Call），适合构建智能体（Agent）应用；
- **MTP 投机解码**：支持多 Token 预测（Multi-Token Prediction）加速推理，服务化部署时吞吐显著提升；
- **开源可商用**：模型权重完全开放，允许商用与二次开发。

## 环境准备

本教程采用 **官方 vLLM Docker 镜像** 部署，无需在宿主机安装 Python/CUDA 等依赖，只需宿主机满足以下条件：

- 一台带有 NVIDIA GPU 的 Linux 服务器（测试机器 4 × 96GB H20）
- 已安装 [Docker](https://docs.docker.com/engine/install/) 与 [NVIDIA Container Toolkit](https://docs.nvidia.com/datacenter/cloud-native/container-toolkit/)（使容器可调用 GPU）
- 宿主机已配置好 NVIDIA 驱动（`nvidia-smi` 可正常显示）

### 拉取 vLLM 镜像

GLM-5.3-Flash 是 8 月底才开源的新模型，采用了稀疏 + 线性混合注意力、mHC（流形约束超连接）等一整套新结构，普通 vLLM 版本跑不起来——模型代码目前只在 vLLM 主干和官方专用镜像 **`vllm/vllm-openai:glm53-flash`** 里，尚未进入任何一个正式版本。

```bash
# 拉取 GLM-5.3-Flash 专属镜像
docker pull vllm/vllm-openai:glm53-flash
```

> 提示：国内用户若拉取官方镜像较慢，可配置 Docker 镜像加速器（如阿里云、DaoCloud 等），或改用等效的国内镜像源。

### 验证 GPU 可用

在宿主机执行以下命令，确认 Docker 能正确识别 GPU：

```bash
docker run --rm --gpus all nvidia/cuda:12.8.0-base-ubuntu22.04 nvidia-smi
```

能正常打印 GPU 信息即说明环境就绪。

## 模型下载

使用 `modelscope` 中的 `snapshot_download` 函数下载模型。新建 `model_download.py` 文件并输入以下内容：

```python
# model_download.py
from modelscope import snapshot_download

model_dir = snapshot_download(
    'ZhipuAI/GLM-5.3-Flash',
    cache_dir='your_model_dir',   # 请修改为你自己的模型下载路径
    revision='master'
)
print(f"模型下载完成，保存路径为：{model_dir}")
```

在终端中执行下载：

```bash
python model_download.py
```

> 注意：请记得修改 `cache_dir` 为你自己的模型下载路径哦~

如果网络环境可以访问 Hugging Face，也可以直接使用：

```bash
pip install -U huggingface_hub
hf download zai-org/GLM-5.3-Flash \
  --local-dir /path/to/GLM-5.3-Flash
```

两种方式任选其一即可，不要重复下载。

## vLLM Serving

使用官方专用 `vLLM` Docker 镜像部署，无需在宿主机安装 Python 环境：

8卡部署示例：

```bash
docker run --gpus all --ipc=host --name glm-5.3-flash \
    -p 8000:8000 \
    -v /models/GLM-5.3-Flash:/models \
    vllm/vllm-openai:glm53-flash \
    --model /models \
    --tensor-parallel-size 8 \
    --gpu-memory-utilization 0.9 \
    --tool-call-parser glm47 \
    --enable-auto-tool-choice \
    --reasoning-parser glm45 \
    --max-num-seqs 128 \
    --no-enable-flashinfer-autotune \
    --speculative-config '{"method":"mtp","num_speculative_tokens":5}' \
    --max-model-len 524288 \
    --served-model-name glm-5.3-flash
```

加载完毕后出现 `Application startup complete.` 说明服务成功启动，服务默认监听 `http://localhost:8000`。

## 接口调用

服务启动后，可以通过兼容 `OpenAI` 的接口进行调用。下面给出两种常用方式。

### 对话调用

```python
# test_chat.py
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",  # 本地 vLLM 服务地址
    api_key="EMPTY",                       # 本地服务不需要真实 key，随便填写即可
)

response = client.chat.completions.create(
    model="glm-5.3-flash",
    messages=[
        {"role": "user", "content": "给我一个关于大模型的简短介绍。"}
    ],
)

# 思考过程存放在 reasoning_content 字段中
print("思考过程：", response.choices[0].message.reasoning_content)
# 最终答案
print("回答：", response.choices[0].message.content)
```

运行：

```bash
python test_chat.py
```

模型的 response 由两部分组成：一部分是思考过程，存放在 `reasoning_content` 字段中；另一部分是最终答案，存放在 `content` 字段中。

### 工具调用（Function Call）

`GLM-5.3-Flash` 原生支持工具调用，下面通过一个查询天气的例子演示完整流程：

```python
# test_tool_call.py
import json

from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="EMPTY",
)

tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "查询指定城市的天气",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {"type": "string", "description": "城市名称"},
                },
                "required": ["city"],
            },
        },
    }
]

def get_weather(city: str):
    # 这里用固定返回模拟真实天气接口
    return f"{city} 今天晴，气温 25℃。"

messages = [{"role": "user", "content": "上海今天天气怎么样？"}]

# 第一次请求：模型决定调用哪个工具
response = client.chat.completions.create(
    model="glm-5.3-flash",
    messages=messages,
    tools=tools,
)
tool_call = response.choices[0].message.tool_calls[0]
func_name = tool_call.function.name
func_args = json.loads(tool_call.function.arguments)
func_out = get_weather(**func_args)

# 将工具执行结果回传给模型，生成最终回答
messages.append(response.choices[0].message)
messages.append({
    "role": "tool",
    "content": func_out,
    "tool_call_id": tool_call.id,
})
final = client.chat.completions.create(
    model="glm-5.3-flash",
    messages=messages,
    tools=tools,
)
print(final.choices[0].message.content)
```

运行：

```bash
python test_tool_call.py
```
